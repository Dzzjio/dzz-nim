# Nim Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Do not run any git commands (no commit, no push); the user handles git.**

**Goal:** A React Nim game (piles 1-3-5-7, misère) playable against a perfect AI or against another person online via room codes.

**Architecture:** npm-workspaces monorepo. `shared/` holds pure TypeScript rules, AI and wire protocol; `web/` is a Vite + React app (Vercel); `server/` is a small Node `ws` server holding in-memory rooms and validating every move with the shared rules.

**Tech Stack:** TypeScript, Vitest, Vite, React 18, `ws`, `tsx` (to run the server).

**Spec:** `docs/superpowers/specs/2026-10-05-nim-game-design.md`

## Global Constraints

- Piles are exactly `[1, 3, 5, 7]`.
- A move removes `count` matches, 1 ≤ count ≤ piles[pile], from one pile. Whoever takes the last match **loses**.
- AI is perfect only; no difficulty levels. In AI games the player chooses who moves first.
- Online: room codes (create/join), no matchmaking. Server is authoritative.
- Reconnect window ~30 s using a per-player token; idle rooms expire.
- Web reads the server URL from `VITE_SERVER_URL`.
- TypeScript everywhere, ESM.
- Out of scope: accounts, ratings, matchmaking queue, chat, spectators, AI levels.
- AI is the classic nim-sum (XOR) strategy, misère version (see spec). Plain nim-sum alone is wrong in misère once exactly one pile has ≥ 2 matches, so that endgame case is handled separately.

## Review Focus

- Move out of turn → server rejects with `error`, state unchanged.
- Illegal counts (0, negative, fractional, larger than pile, bad pile index) → rejected, both in `applyMove` and at the server.
- Move after the game is over → rejected.
- Joining a nonexistent or full room; lowercase room code → clear error / code matched case-insensitively.
- Malformed or non-JSON WebSocket messages → `error` reply, connection stays up.
- Reconnect with a wrong token → rejected; opponent disconnect → opponent notified.
- Double-click / rapid repeat moves in the UI → only one move applied.

- [ ] **Step 1:** Write `ai.test.ts`:
  - `bruteWinning` (oracle: memoised recursion, a move that empties the board loses for the mover) is false for `[1,3,5,7]` and true for `[1,3,5,6]`.
  - Misère edge cases: `[1,0,0,0]` is a loss for the mover; `[2,0,0,0]` is a win (take 1 and leave one).
  - Exhaustive: for every position with piles ≤ `[1,3,5,7]` where `bruteWinning` is true, `aiMove` returns a legal move leading to a position where `bruteWinning` is false for the opponent.
  - Named cases: `[0,0,0,5]` → take 4 (leave one 1-pile); `[1,0,0,5]` → take 5 (leave odd count of 1-piles = 1).
  - From a losing position, `aiMove` returns a legal move.

### Task 3: Wire protocol + room logic

**Files:** Create `shared/src/protocol.ts`, `server/package.json` (name `@nim/server`, deps `ws`, `@nim/shared`; devDeps `tsx`, `vitest`, `@types/ws`), `server/src/rooms.ts`, `server/test/rooms.test.ts`; modify `shared/src/index.ts`.

**Interfaces:**
- Produces in `@nim/shared`:
  - `type ClientMsg = {type:'create'} | {type:'join'; code:string} | {type:'reconnect'; code:string; token:string} | {type:'move'; move:Move}`
  - `type ServerMsg = {type:'joined'; code:string; token:string; seat:Player} | {type:'state'; state:GameState} | {type:'opponent'; connected:boolean} | {type:'error'; message:string}`
- Produces in `server/src/rooms.ts` (pure, no sockets): `class RoomManager` with
  - `constructor(opts?: { now?: () => number; reconnectMs?: number; idleMs?: number; random?: () => number })` (defaults 30000, 600000)
  - `createRoom(connId: string): { code: string; token: string; seat: Player }`
  - `joinRoom(code: string, connId: string): { token: string; seat: Player; state: GameState } | { error: string }` — code matched case-insensitively; when seat 1 joins, `state = initialState(first)` with `first` chosen by `random`
  - `reconnect(code: string, token: string, connId: string): { seat: Player; state: GameState | null } | { error: string }`
  - `move(connId: string, move: Move): { state: GameState; to: string[] } | { error: string }` — rejects unknown connection, game not started, out of turn, illegal move
  - `disconnect(connId: string): { opponentConnId: string | null }`
  - `sweep(): void` — drops rooms whose disconnected seat exceeded `reconnectMs` or that were idle > `idleMs`
  - `connIds(code: string): string[]`
